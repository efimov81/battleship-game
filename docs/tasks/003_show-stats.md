# Задача: статистика флота противника

Добавить рядом с игровым полем противника визуальную статистику его кораблей.

**Отображать стандартный состав флота:**
- 1 корабль × 4 клетки
- 2 корабля × 3 клетки
- 3 корабля × 2 клетки
- 4 корабля × 1 клетка

**Визуализация:**
- Белый цвет — корабль ещё не уничтожен.
- Красный цвет — корабль потоплен.
- Каждый корабль отображать отдельной полоской из соответствующего количества клеток.
- При потоплении корабля обновлять статистику автоматически, без перезагрузки страницы.

**Логика:**
- Использовать существующее состояние игры и результаты выстрелов.
- Не раскрывать координаты непотопленных кораблей противника.
- Подбитый, но ещё не потопленный корабль остаётся белым.
- При потоплении менять цвет ровно одного корабля соответствующего размера.
- Статистика должна корректно сбрасываться при создании новой партии.

Использовать существующую архитектуру Angular и backend. Не дублировать игровую логику на frontend.
